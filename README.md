# sshkeygen.dev

Free SSH key generator that runs in your browser. Ed25519, RSA and ECDSA keys in OpenSSH format, with an optional passphrase. Nothing is sent anywhere.

https://sshkeygen.dev

## Development

```bash
npm install
npm run dev
npm test
npm run build
```
